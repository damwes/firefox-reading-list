# Firefox Reading List

A minimal Firefox extension for saving pages to read later.

## How to use:
- Click the browser action (a button in a panel) to open or close the sidebar.
- Click the "+ Add current tab" button to add the page to your reading list.

The extension organizes tabs into two sections: "Unread" and "Already read." You can mark a tab as read or simply remove it from the list.
